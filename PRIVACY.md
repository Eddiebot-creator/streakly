# Privacy Policy

Streakly stores the minimum data needed to sync habit progress across devices.

## Data Stored
- Email address and display name from Firebase Authentication
- Habit titles, categories, icons, frequency, and reminder time
- Completion dates, current streak, best streak, and total completion counts
- Basic leaderboard totals when the user completes habits

## User Controls
- Export habit data from Settings as CSV
- Request password reset from Settings
- Request email verification from Settings
- Review the privacy summary from Settings

## Roadmap Controls
The production delete-account workflow should require recent reauthentication before permanently deleting account and habit data.

## Third Parties
Streakly uses Firebase Authentication and Cloud Firestore for login and cloud sync.
