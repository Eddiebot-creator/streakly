# Streakly

A production-ready Flutter habit tracker for Android and Windows with Firebase Auth, Firestore database, streak tracking, statistics, leaderboard, settings, and local reminders.

## Run
```powershell
flutter pub get
flutterfire configure
flutter run -d windows
# or
flutter run -d android
```

## Firebase collections
- users
- habits
- completions

## Important
Run `flutterfire configure` to generate `lib/firebase_options.dart` before running with Firebase.
